# クイズ大会一括管理 Webアプリ

60〜100チーム規模で実施可能な、リアルタイムクイズ大会システムです。
プロジェクター用の大画面プレゼンテーション、参加者のスマートフォン回答端末、主催者用の管理者コントロールパネルがリアルタイムに連動します。

## 🚀 使い方・動作確認手順

### 1. ローカルテスト（Firebase未設定でも即座にテスト可能）
Firebaseのキーをまだ貼っていなくても、同一ブラウザ内で各タブを開くだけで完全なリアルタイム同期テストが可能です。

1. `Quiz/admin.html` をブラウザで開きます。
2. 別タブで `Quiz/presentation.html` を開きます。
3. 別タブ（またはスマートフォンのブラウザ表示）で `Quiz/player.html` を開きます。
4. `admin.html` で「**60チーム生成**」をクリックすると、一瞬で60チームが登録されます。
5. 「**▶ クイズ開始**」を押し、「**2. 出題・回答受付**」を押すと問題が出題されます。
6. 「**一括回答実行**」を押すと、全チームの回答がランダムに送信され、プレゼン画面の水位がリアルタイムにぐんぐん上昇します！
7. 「**4. 正解発表・解説**」を押すと、正解発表、解説表示、および回答速度ボーナスを含む得点が自動集計されます。

## 🔑 Google Firebase APIキーの設定方法

Firebase Realtime Database を利用して本番運用する場合、以下の2通りのいずれかで設定できます。

### 方法A: 管理画面から貼り付け（推奨・最も簡単）
1. `admin.html` をブラウザで開きます。
2. 右上の「**⚙️ Firebase設定**」ボタンをクリックします。
3. Firebase Consoleから取得した `firebaseConfig` のJSONを貼り付け、「保存して接続」をクリックします。

### 方法B: コードを直接編集
`Quiz/js/firebase-config.js` を開き、以下の部分を書き換えてください：

```javascript
const FIREBASE_CONFIG_DEFAULT = {
  apiKey: "YOUR_API_KEY",
  authDomain: "YOUR_PROJECT_ID.firebaseapp.com",
  databaseURL: "https://YOUR_PROJECT_ID-default-rtdb.firebaseio.com",
  projectId: "YOUR_PROJECT_ID",
  storageBucket: "YOUR_PROJECT_ID.appspot.com",
  messagingSenderId: "YOUR_MESSAGING_SENDER_ID",
  appId: "YOUR_APP_ID"
};
```

#### Firebase Realtime Databaseのセキュリティルール設定例
Firebase Consoleの「Realtime Database」→「ルール」で以下のように設定すると動作します：
```json
{
  "rules": {
    ".read": true,
    ".write": true
  }
}
```

## 🎯 主な機能と特徴

### 1. プレゼンテーション表示画面 (`presentation.html`)
- **中央揃えレイアウト**:
  - 問題画像（あれば）
  - 問題文
  - 制限時間バー（タイマー進行時）
  - 選択肢（2列配置 `◯◯ / ◯◯ / ◯◯`、画像あれば挿入）
- **水位上昇アニメーション**:
  - 回答済みチーム数が100%に近づくほど、画面下部から水が溜まっていくダイナミックな波打ち描写。
- **制限時間接近警告**:
  - 残り時間5秒以下（または20%以下）になると、バーの点滅と画面全体の赤い警告パルスアニメーションが発生。

### 2. スマートフォン回答画面 (`player.html`)
- **常時表示ヘッダー**:
  - チーム名、現在の得点、何問目か、現在の順位（設定された問題数まで表示、以降非表示）。
- **待機シーン**:
  - 「運営者の指示に従ってください」と表示。
- **回答シーン**:
  - 問題画像、問題文、選択肢1〜6、ロックボタン。
  - **ロックボタンを押すと背景が選択肢の色（赤/青/黄/緑/水色/紫）に応じて変化**し、回答が確定。
- **回答後シーン**:
  - 正解/不正解の大きな判定バナー。
  - 何点増加したか、全体の正解率（%）、解答解説。
  - 現在の順位一覧表示（自分のチームへ自動スクロールフォーカス）。
- **結果発表シーン**:
  - 自身の最終順位と得点、全チームの順位一覧。

### 3. 管理者コントロールパネル (`admin.html`)
- **クイズの開始・停止**:
  - ワンクリックで大会の開始/停止を切り替え。
- **人数の設定 (デフォルト100組)**:
  - 想定組数を設定可能（プレゼン画面の水位計算基準）。
- **得点数のリセット**:
  - 全チームの得点と回答ログを一括リセット。
- **リアルタイムタイマー切替**:
  - 時間制限付き問題をワンクリックで手動進行に切り替え、または即時強制締切が可能。
- **得点ボーナス設定（4種類 + 基本点）**:
  - 速かった上位3グループ（Top1, Top2, Top3）
  - 正解者の中で上位50%
  - 正解者の中で下位50%
  - 単独正解特別ボーナス
  - 基本正解点
- **順位表示制限設定**:
  - 「第◯問まで表示」を設定でき、大会終盤に順位を伏せて結果発表で盛り上げることが可能。
- **問題GUI & JSONエディタ**:
  - 2〜6択の選択肢追加/削除、画像パス指定、JSONインポート/エクスポート。
