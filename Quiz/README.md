# クイズ大会一括管理 Webアプリ

60〜100チーム規模で実施可能な、リアルタイムクイズ大会システムです。
プロジェクター用の大画面プレゼンテーション、参加者のスマートフォン回答端末、主催者用の進行管理パネルおよび問題・大会設定画面がリアルタイムに連動します。

## 🚀 使い方・動作確認手順

### 1. ローカルテスト（Firebase未設定でも即座にテスト可能）
Firebaseのキーをまだ貼っていなくても、同一ブラウザ内で各タブを開くだけで完全なリアルタイム同期テストが可能です。

1. `Quiz/admin.html` をブラウザで開きます。
2. 別タブで `Quiz/presentation.html` を開きます。
3. 別タブ（またはスマートフォンのブラウザ表示）で `Quiz/player.html` を開きます。
4. `admin.html` の「**動作テスト・シミュレーション**」では想定参加組数がチーム数欄に反映されます。「**👥 ダミーチーム生成**」で一括登録します。
5. 「**▶ クイズ開始**」を押して出題を開始します。
6. 「**⚡ 回答シミュレーション**」を押すと、登録全チームの回答がランダムに送信され、プレゼン画面の水位がリアルタイムに上昇します。
7. 「**正解を発表する**」を押すと、正解発表、解説表示、および得点が自動集計されます（画面内に見切れず綺麗に収まります）。
8. 最終問題が終了すると「**最終結果発表**」に進み、プレゼン画面の「次の順位を発表する」ボタン（または管理画面の発表ボタン）で、10位から1位まで順位・チーム名・得点を1チームずつ発表できます。「1位まで自動再生」や「最初から」も使えます。

### 2. 複数のクイズを管理する
1. `admin.html` または `setting.html` 上部の「使用中クイズ」から、実施するクイズを選択します。
2. 「クイズ追加」で現在の問題・出題順・チーム名一覧を複製したクイズを作成できます。大会状態と得点は新規に初期化されます。
3. クイズを切り替えると、開いている進行・回答・プレゼン・モニター画面にも選択が反映されます。Firebase接続時は別端末にも同期されます。
4. 選択中クイズは「削除」で削除できます。既定のクイズは削除できず、既存の保存データも引き続き利用できます。

## 🎯 今回の機能強化・改修点

1. **白基調・メリハリのあるソリッドデザイン**
   - 青グラデーションを全廃し、白とクリーンなライトグレーを基調に、視認性の高いブラック・濃紺テキストとソリッドカラーでメリハリのあるデザインに刷新。
2. **プレゼンテーション画面の見切れ防止**
   - 画面高さ（100vh）内で問題文・画像・選択肢・解答解説がスクロールせず確実に収まる動的レスポンシブ設計を適用。
   - ポイント倍率を問題ごとに設定でき、2倍・3倍・その他で専用ラベルを表示。
3. **最終結果の10位〜1位個別発表**
   - 「10位」から「1位」まで、順位・チーム名・得点を1チームずつ画面に表示。
   - 「次の順位を発表する」ボタン（またはSpaceキー/Enterキー）による手動進行、および「1位まで自動再生」に対応。
4. **問題データ管理・大会設定の分離 (`setting.html`)**
   - 管理パネルから問題のGUI編集・JSON読込/書出、出題順並べ替え、想定チーム数、得点ボーナス設定を `setting.html` に分離。
   - 出題順管理から問題を非表示にできます。非表示の問題は出題番号に含まれず、問題データは保持され、再表示も可能です。
   - 進行パネル（`admin.html`）はスッキリと進行コントロールに特化。
5. **動作テスト・シミュレーションの強化**
   - 進行管理画面の簡易回答状況の下に、ダミーチーム生成と回答シミュレーションを配置。
6. **記述式問題・独立回答モニター**
   - 問題設定で記述式を選択すると、参加者は文字で回答し、`monitor.html` で回答を確認して手動採点できます。
   - 1行につき1つ複数登録できる模範解答のいずれかと完全一致する回答は自動正解とし、それ以外は手動採点できます。問題ごとの倍率は正の数値で設定でき、2倍・3倍・その他に応じた名称を表示します。
   - 回答モニターは現在の回答状況と過去の回答状況をタブで切り替えられます。過去の画面ではチームごとの合計点と各問題の獲得点を一覧表示し、表示する問題を絞り込むと合計点もその問題だけで再計算されます。チームIDまたは合計点で並べ替えできます。
   - 進行管理画面には登録・回答済み・未回答の簡易集計を残しています。
7. **チームの多重ログイン防止**
   - 同じチームで新しい端末がログインすると回答権を引き継ぎ、以前の端末はログアウトします。回答送信時にもセッションを確認し、古い端末からの送信を拒否します。
8. **出題・プレゼン操作**
   - 出題順はボタンまたはドラッグ＆ドロップで変更でき、プレゼン画面のプレビューと回答画面QR表示を進行管理画面から操作できます。
9. **プレイヤー画面の回答割合**
   - 解答解説の直前に、選択式はチーム全体を100%とした選択肢別の積み上げ横棒グラフ、記述式は採点済み回答を正答・誤答に分けた1本の積み上げ横棒グラフで表示します。選択式は回答ボタンと同じ色で表示し、正解と本人の選択肢をグラフ内で強調します。記述式の未採点回答は割合に含めず件数を別に表示します。
10. **司会用画面 (`host.html`)**
   - クイズ進行と同期して現在の問題・問題画像・選択肢（画像付き選択肢はプレイヤー画面同様のカード表示）・正解と解説を表示し、問題ごとの司会メモをFirebaseに保存できます。問題を手動選択するとページ再読み込みまで進行との同期が止まり、事前準備ができます。現在の上位3チームもリアルタイムで確認できます。
