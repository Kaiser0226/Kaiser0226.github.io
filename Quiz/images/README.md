# クイズ用 画像保存フォルダ

このフォルダに問題および選択肢の画像を配置してください。

## 推奨ファイル命名規則（自動紐付け対応）
問題IDが `1` の場合：
- **問題メイン画像**: `q_1_main.png` （または `.jpg`, `.jpeg`, `.webp`, `.svg`）
- **選択肢画像**:
  - 選択肢1: `q_1_opt_1.png`
  - 選択肢2: `q_1_opt_2.png`
  - 選択肢3: `q_1_opt_3.png`
  - 選択肢4: `q_1_opt_4.png`
  - 選択肢5: `q_1_opt_5.png`
  - 選択肢6: `q_1_opt_6.png`

※問題管理画面（`admin.html`）のGUIエディタまたはJSONデータ内で、独自の画像ファイルパス（例: `images/sample.jpg` や 外部URL `https://...`）を直接指定することも可能です。
